# Real NAS runtime evidence

This is the accepted NAS animation evidence. It is generated by executing the repository's DARTS implementation locally; it is not a hand-authored reel and it does not use the committed genotype fixture as a fallback.

## Reproduce

From the repository root:

```powershell
py -3.12 scripts/smoke_test.py
py -3.12 scripts/generate_real_runtime_video.py
```

The generator runs `configs/smoke_cpu.yaml` through `DartsTrainer.fit()`, using the repository's deterministic synthetic loader. It then runs the searched `DartsNetworkCIFAR` and a `NetworkCIFAR` rebuilt from the measured genotype. CPU execution is intentional on this laptop; the run reports `torch 2.7.1+cpu`, `device=cpu`, `cuda_available=false`, and does not claim GPU performance.

## Preserved outputs

| Artifact | What it contains |
| --- | --- |
| [`nas-runtime.mp4`](runtime-evidence/nas-runtime.mp4) | Eight-stage animation rendered from the measured run: batch, forward, search, genotype, compiled forward, and export. Repeated frames only make each measured stage viewable. |
| [`nas-runtime-poster.png`](runtime-evidence/nas-runtime-poster.png) | Poster for the actual DARTS search epoch and its measured loss/accuracy values. |
| [`nas-runtime-trace.csv`](runtime-evidence/nas-runtime-trace.csv) | Stage-by-stage values copied from the run, including tensor shapes, losses, metrics, genotype, and checkpoint digest. |
| [`nas-runtime-summary.json`](runtime-evidence/nas-runtime-summary.json) | Full runtime record, source/config boundary, output hashes, genotype, tensor statistics, and limitations. |

The local checkpoint is written to `search_checkpoints/real_runtime/last_search.pt`, which is ignored because model binaries are not committed. Its SHA-256 is recorded in the JSON evidence. The checked-in JSON, CSV, poster, and MP4 preserve the observable results without pretending that a binary checkpoint is part of the repository.

## Honest boundary

The input is the repository's synthetic CIFAR-shaped smoke dataset (`8` train, `8` validation, and `8` test tensors). The one-epoch search verifies that data loading, architecture updates, forward passes, genotype derivation, checkpointing, and discrete compilation work together. It is not a CIFAR-10 accuracy result, a trained production model, or a GPU benchmark.

The older `docs/animation/nas_search_sequence.json` and `frontend/public/animation/nas-search-reel.html` remain legacy visual-reference assets required by the existing test. They are not used as evidence for this rebuild; use the runtime-evidence files above.
